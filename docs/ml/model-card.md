# Model Card

## Общая информация

**Название модели:**  

Intent Classifier (ruBERT-tiny2) 

**Источник:**  
https://huggingface.co/Gleckus/intent-classifier-rubert-tiny2

**Автор / организация:**  
Gleckus

**Задача модели:**  
Классификация текста — определение намерения (интента) сообщения в русскоязычном чат-боте. Исходная модель различает 3 класса: `rag`, `chat`, `followup`.

**Язык:**  
Русский

## Использование в проекте

Модель используется для классификации намерений пользователя в ИИ-боте для записи к врачу. После отправки сообщения текст передаётся модели, которая предсказывает категорию запроса. Результат передаётся системе для последующих действий(создание записи, удаление записи, перенос записи).

Важно: для проекта требуется дообучение модели на целевых классах (make_appointment, cancel_appointment, list_appointments, unknown), так как исходный набор классов не совпадает с бизнес-логикой бота.

Извлечение сущностей (например, doctorName, dateTime) — отдельная задача, которая решается другим компонентом и не входит в возможности этой модели, нужна отдельная модель для выявление сущностей.

## Входные данные

Сообщение от пользователя

## Выходные данные

label — предсказанный класс намерения;

score — уверенность модели (float).

## Метрики качества

На исходном тестовом наборе автора модели: F1 ≈ 0.90 (для 3 классов rag, chat, followup). Метрика не отражает качество на целевых классах проекта — после дообучения потребуется повторная оценка Precision, Recall и F1 на размеченной выборке сообщений пациентов.

## Ограничения

- Модель обучена только на русском языке;

- Модель не предназначена для медицинских решений;

- Потенциальное ограничение для нашего проекта: Модель обучена только для 3 намерений(rag,chat,followup), поэтому требует дообучения для ИИ-бота;

- Потенциальное ограничение для нашего проекта: Модель не умеет определять именованные сущности, поэтому нужен дополнительный блок для выявления их;

## Не рекомендуется использовать

- Для языков, отличных от русского.

- Для извлечения сущностей — модель этого не умеет.

- Без дообучения — для классификации намерений, не входящих в исходный набор (rag, chat, followup).
