# ИИ-бот для записи к врачу

Сервис на базе ИИ для управления записями к врачу через диалог с пользователем: создание, перенос и удаление/отмена записи.

Основные пользователи:

- пользователь;

Основные функции:

- запись к врачу;

- перенос записи к врачу;

- отмена записи к врачу;

- просмотр записей.


## Комплект документации


1. Описание проекта

    Для всех участников команды, чтобы зафиксировать цели продукта.

2. Требования

    Для разработчиков, тестировщиков и т.д, чтобы точно определить функциональность и критерии приемки системы.

3. Архитектура системы

    Для разработчиков и технических архитекторов, чтобы описать структуру компонентов, их взаимодействие и технические решения.

4. Документация API

    Для разработчиков и тестировщиков, чтобы обеспечить корректное взаимодействие с сервером через программные интерфейсы.

5. Документация ML-модели

    Для ML-инженеров и разработчиков, чтобы описать процесс обучения, метрики качества и способ интеграции модели в сервис.

6. Руководство пользователя

    Для конечных пользователей, чтобы объяснить, как управлять записями к врачу через диалог с ботом.

7. Руководство по обработке ошибок

    Для службы поддержки и разработчиков, чтобы стандартизировать действия при сбоях и понимать коды ошибок системы.
