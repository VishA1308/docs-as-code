### US-01. Запись к врачу

Как пользователь,
я хочу автоматически записываться к врачу через ИИ-бота, 
чтобы не звонить в регистратуру или ждать от них звонка.

Критерии приёмки:

- система принимает текст сообщения;
- система получает варианты свободных слотов для записи к врачу;
- система предлагает полученные варианты пользователю для выбора;
- пользователь выбирает и отправляет система выбранный вариант;
- после обработки отображается информация об успешной записи;
- если запись не выполнена, пользователь получает сообщение об ошибке.


### US-02. Просмотр записей

Как пользователь,
я хочу видеть свои записи к врачам,
чтобы не запоминать дату и время каждой записи.

Критерии приёмки:

- система принимает запрос на просмотр записей;
- после обработки отображается список моих записей с датой и временем;
- если записей нет, система сообщает, что записей не найдено;
- если при получении списка произошла ошибка, пользователь получает сообщение об ошибке.

### US-03. Отмена записи к врачу

Как пользователь,
я хочу отменить запись к врачу через ИИ-бота,
чтобы не звонить в регистратуру.

Критерии приёмки:

- система принимает текстовое сообщение с намерением отменить запись;
- после обработки отображается подтверждение отмены;
- если отмена невозможна, пользователь получает сообщение об ошибке и причину.

### UC-01. Запись к врачу

Актор: пользователь

Цель: записаться к врачу через ИИ-бота.

Предусловие: пользователь начал диалог с ботом.

Основной сценарий:

1. Пользователь отправляет сообщение с намерением записаться к врачу.
2. Система передаёт текст ML-модели.
3. ML-модель определяет намерение «запись к врачу» и извлекает параметры: специальность, врач, дата, время.
4. Система получает доступные варианты записи.
5. Система предлагает пользователю варианты даты и времени.
6. Пользователь выбирает подходящий вариант.
7. Система сохраняет информацию о записи в базе данных.
8. Система подтверждает пользователю успешную запись.

Альтернативный сценарий:

Если ML-модель не распознала запрос или нет свободных слотов,
система сообщает об ошибке, предлагает изменить параметры
или обратиться в регистратуру для ручной записи.

Результат: запись создана через ИИ-бота или пользователь получил инструкцию для ручной записи.
